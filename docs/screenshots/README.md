# Screenshots

Capture screenshots after configuring actual hospital resources and signing in with provisioned clinical staff accounts.

Suggested screenshots:

| File | Description |
|---|---|
| `dashboard.png` | Live dashboard showing configured beds, doctors, and current queue |
| `intake.png` | Patient intake form (use synthetic information only for screenshots) |
| `analytics.png` | Analytics charts with test data only |

Do not include real patient-identifiable information in screenshots, sample data, presentations, or public repositories.
